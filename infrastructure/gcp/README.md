# Google Cloud

A Google Cloud equivalent of the reference implementation is planned for a future release.

The deployment would use:

- Cloud Functions for the registry handler
- Firestore for the registry, articles, locations, and documents collections
- Cloud CDN and Cloud Load Balancing for edge routing and custom domain

If you have built a GCP implementation, contributions are welcome. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for guidelines and refer to [SPEC.md](../../SPEC.md) for the specification.
