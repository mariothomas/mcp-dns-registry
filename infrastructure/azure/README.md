# Azure

An Azure equivalent of the reference implementation is planned for a future release.

The deployment would use:

- Azure Functions for the registry handler
- Cosmos DB for the registry, articles, locations, and documents tables
- Azure Front Door for edge routing and custom domain

If you have built an Azure implementation, contributions are welcome. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for guidelines and refer to [SPEC.md](../../SPEC.md) for the specification.
